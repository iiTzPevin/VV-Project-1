Where the toggles land · offset from the nearest dclk edge

Relatively prime periods sweep the phase: each toggle lands at a new offset, and the sequence walks through the window (shaded) rather than around it. Filled dots have already happened; hollow ones are coming.

What this models. A capture violates iff a data toggle lands inside [edge − setup, edge + hold] — that is the whole physics, kept at the abstraction where it is honest. A violating capture goes metastable and settles to the old or the new value by a seeded draw, independently per flop instance — which is why the raw wire feeds two instances here, A and B: on a violating edge they can disagree, and downstream logic reads an impossible state. The windows are model-sized (tenths of a nanosecond); on a production cell they are picoseconds, which changes the rate, not the mechanism.

What the synchronizer buys. With the toggle on, the raw wire feeds s1, and logic reads s2. s1 may still go metastable — that is allowed. It gets a full destination cycle to settle before s2 samples it, so logic always sees a clean, consistent level; only the arrival cycle (old value vs new) stays uncertain. The model assumes s1 settles within one cycle — each added stage multiplies the mean time between failures (MTBF). One synchronizer, then fan out: two separate synchronizers on one signal recreate the disagreement. A multi-bit bus needs more than per-bit synchronizers — bits settle on different cycles; gray-code the value or use a handshake.

Why simulation is silent. Zero-delay RTL simulation orders every event on clock edges; setup and hold windows do not exist in its event model, so the mid-transition sample cannot be represented — no stimulus, seed count, or run length changes that. Correctness here is structural, which is why CDC signoff is a structural-analysis tool that reads the netlist for unsynchronized crossings and never runs your testbench. Same seed, same resolutions: the randomness is mulberry32, keyed by seed and edge index.
